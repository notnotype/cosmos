更新触发、文档影响结论、建议字段及审核修改流程统一维护在[日常文档更新与代理协作](../../../../docs/standards/repository-workflow.md#日常文档更新与代理协作)。本任务只维护实施范围、责任分工和验收状态；最初计划依据保留在 [walkthrough](walkthrough.md)。

## 责任与审核

- Otirik：Task Leader、当前架构决策人、文档负责人和最终审核人。
- Notype：架构顾问及历史设计依据提供者，不承担当前最终审批。
- 主代理：范围控制、审核文档建议、分派文档修改、审查证据和汇总门禁；具体架构取舍由 Otirik 决定。
- 代码实现代理：只改登记的实现/测试/检查工具集合；发现文档偏差时提交建议，不直接修改文档库，包括文档入口与规则。
- 文档代理：只修改主代理接受并登记的文档集合；不得借机改产品行为或改写历史事实。
- 独立审查代理：只读核对规则一致性、检查能力及证据边界；不替代 Otirik 最终验收。
