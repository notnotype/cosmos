# Architecture Decision Records

ADR 只记录已经稳定、需要长期保留的决定。仍在探索或会随下一轮需求调整的内容保留在 `docs/architecture/` 和对应 Task。

文件名使用四位编号，例如：

```text
0001-durable-workflow-runtime.md
```

每份 ADR 至少包含 Context、Decision、Consequences 和 Revisit Gate。
